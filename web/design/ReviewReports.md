# 审查报告与测试解释页

本页是已有 Sciver 应用内的阅读界面，沿用应用的导航、字体及黑色、蓝色、白色主题。私有报告存放在各工作区 state 目录的 `reviews/<slug>/report.json`，不随公开 SDK 分发，不依赖 Graph Research。

列表页 `/reviews/` 按归档记录展示标题、快照时间、结论摘要和范围。支持本地搜索以及测试结果/历史审查筛选。保留所有旧深链、勘误和下载。独立详情页沿用 `/reviews/<slug>/`，不把多批次的历史解释累加到一个巨大页面。

测试解释按读者的问题组织：结论、逐题结果、消耗口径、连续质量、运行环境与后续准备、原始记录。桌面使用窄目录和正文两栏；手机将目录放到正文之前，并把逐题表格改为带完整字段的纵向列表。展开后的逐题指标也按名称、完整数值、比较方向逐条显示，无需横向滚动查看分数；其他宽的对照表可在自身容器内横向滚动。只显示报告快照，不声称是实时运行状态。

## 视觉约定

- 字体、背景、正文、次要文字、线条、链接均继承 `--tm-*`。页面标题 27–38px，章节 22px，正文 14–17px；数值使用等宽数字。
- 通过色为 `#6ee7b7`，未通过色为 `#fca5a5`，连续评分色为 `#f5cc80`；白色主题分别使用 `#126747`、`#a91e3a`、`#805000`。状态同时显示文字，不只依靠颜色。
- 用空白和轻分隔线组织报告；逐题速览是可导航的真实评分索引。使用 6–8px 圆角，不引入渐变、额外字体、装饰图或自动播放效果。
- 内容自带唯一 H1，审查路由隐藏重复的 shell 页头。保留顶部面包屑、左侧导航及账号管理。
- 所有过滤器有按下状态；明细按钮支持键盘并维护展开状态。空列表、搜索无结果、缺失评分及大附件预览截断均有说明。

## 数据合同

旧报告的 `title/reviewed_at/scope/result/columns/metrics/notes/details` 保持兼容。可增加 `snapshot_at`、`series`、`category`、`archive_summary` 和 `detail_groups`。

测试详情增加可选 `benchmark`：

- `results` 保存归档时的逐题评分与用量投影，包括官方布尔评分分母、原生 Goal 状态、原始 token 字段和墙时。
- `case_context` 提供题目说明、官方来源、冻结原题/计划下载及原始指标比较方向。原题内容位于私有附件中。
- `case_notes` 提供有证据支持的逐题摘要；`quality_comparison` 提供逐项均值、标准误及公开基线比较。
- `environment` 记录历史环境差异；`preparation` 是明确标注时间的下一轮准备快照，包含模型、推理档位、Cycle 上限和逐题准备情况。
- `details` 只允许下载本报告白名单中的普通文件，拒绝目录穿越和符号链接。支持 `preview=false`，不把所有大型文件塞入初始 DOM；可按 `group` 收拢逐题附件。

官方整题通过、模型自行结束、执行上限和准备状态分别呈现。连续评分缺失不记为 0 分，不将多指标交叉优势合成为任意总分。缓存输入和推理输出分别是输入、输出的子集；墙时之和不是整批经过时间或 CPU 核时。不会由页面访问触发模型、评分或科研状态修改。

## 验证

`web/tests/test_review_reports.py` 使用公开玩具数据检查布尔分母与缺失评分、历史兼容、转义、精确下载、路径边界、筛选、展开和窄屏排版。浏览器测试以 `TM_BROWSER_E2E=1` 开启，不调用模型。实际私有报告内容另在本地核验，不能写入测试夹具或公开仓库。
