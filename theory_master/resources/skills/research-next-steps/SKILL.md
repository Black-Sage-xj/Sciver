# 规划下一步

读取 Goal、Contract、Final Gate、当前图谱路径与最新运行状态，说明下一步需要缩小哪个关键不确定性。根据影响、可区分性、已有证据和成本比较少量具体选项，避免提出与现有封闭路径重复的工作。

建议应包含目标路径/H ID、要验证的命题、决定性检验及成功/失败时的后续选择。区分所需改动：Research Plan 的哪段与具体内容、下一轮精确猜想及检验、Scientific Model 是否需要有证据的修订、路径保留/暂停/关闭、运行暂停/启动/恢复。不需要的类型不列入；只想试一个新猜想不自动要求重写整个计划。不要把 proposed plan 写成已完成进展，也不要把人类猜想写成 Scientific Model 的已证实认识。

形成可执行推荐时，在末尾按 1、2、3 编号列出具体变更、理由、对当前工作的影响及生效时点，询问是否按这些项执行或想修改哪里；仅比较概念且没有方案时不机械询问。下一轮猜想默认在下一次全新提案只使用一次，不改写已冻结 Cycle；立即转向必须明确授权安全中断。用户接受特定编号方案、选择部分项、修改后接受或明确下达执行指令时，读取 `research-intervention/SKILL.md`，按最新意图执行，无需重复确认。同意改计划不自动授权启动；运行须在接受范围内。执行后逐项说明已改、待生效、已运行、失败或部分完成及记录链接。未获执行指令时保持只读。
