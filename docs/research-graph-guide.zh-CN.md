# 图谱使用指南

[返回 README](../README.zh-CN.md) · [English](research-graph-guide.md)

图谱记录研究如何从猜想走向证据和结论，以及后续问题如何产生。打开任务的“图谱”入口，或进入 `/research-explorer/` 选择科研任务。工具栏右侧的 **?（图谱使用说明）** 按钮可随时打开说明弹窗；点击“关闭”、按 Esc 或点击弹窗外关闭，全屏时也可使用。

工具栏的 **笔记库** 显示 Markdown 文件夹的完整路径，提供复制路径、用 Obsidian 打开、下载整个笔记库和选择输出位置。文档旁可复制文件路径、在 Obsidian 打开或另存副本。同机桌面连接还可直接打开文件夹；远程使用时在本机打开下载或同步后的库，并填写本机 Obsidian 库名。

`exploration.canvas` 位于笔记库根目录，随图谱自动更新，直接引用现有 Markdown。可为选定猜想生成持续更新的分支 Canvas，也可另存全图或分支快照。Markdown 首次发布后保留原文和人工编辑；刷新 Canvas 只更新图谱文件。网页报告与 Obsidian 读取同一份正文，正式科研状态仍由数据库维护。

输出位置分为整库移动和本机另存副本。移动整库前暂停 Runner、Worker 及调度器，在“输出位置”选择空文件夹；移动保留任务身份与计算数据。新任务也可用 `sciver new research_plan.md --vault-root /absolute/empty/folder` 选择笔记库目录。

## 1. 先理解猜想、Cycle 与 Outcome

- **猜想（Hypothesis，H）**：一个可检验的科学命题，包含适用条件、研究范围和判别标准。
- **Cycle**：围绕冻结命题开展的一轮研究。每个新科研 Cycle 冻结一个新的 H；同一轮恢复、重试和 Judge 返工继续沿用该 H。
- **Outcome**：Judge 对本轮冻结命题的终局科学裁决及其理由、发现、未解决问题、适用边界、证据和报告。每个有终局科学裁决的 Cycle 恰有一个 Outcome。

Outcome 嵌在 H 卡片里。历史宽泛 H 可以关联多个 Cycle 的 Outcome，需逐轮阅读冻结命题与范围；局部支持或反驳的效力以该轮范围为准，整体 H 的判断单独记录。

图谱主要有 **H 与 External 两类节点**。Outcome 属于 H 的阅读内容。历史 Canvas 视图可能仍保留 Decision、Finding、StageSummary 节点，阅读时核对其来源和范围。

## 2. Outcome 有哪几种状态

正式科学裁决有三种：

| 页面状态 | 字段值 | 含义及阅读重点 |
|---|---|---|
| 支持 | `supported` | 证据在本轮条件与检验范围内支持命题。阅读适用边界，确认支持覆盖了什么。 |
| 否决 | `rejected` | 证据反驳本轮命题。阅读反例和失败机制，这些也能指导后续研究。 |
| Open | `open` | Judge 已完成本轮裁决，认定现有证据仍无法判定命题成立或不成立。阅读裁决理由、未解决问题和需要补充的判别条件。 |

图例中的其他标签帮助区分进度、阶段性保全和历史兼容情况：

| 页面标签 | 展示值 | 含义及阅读重点 |
|---|---|---|
| 待裁决 | `none` | 尚无可展示的科学裁决。到 Cycle 运行页查看正在进行、失败或其他执行状态；这个标签与 Judge 已裁决的 Open 有区别。 |
| 研究中止·未裁决 | `unadjudicated` | 执行未完成时保全的阶段性材料，未经终局 Judge 科学裁决。详情可能列出中止原因、已有发现和未完成的返工要求。 |
| 多轮结论不一 | `mixed` | 历史 H 的多轮 Outcome 展示分类不同。逐条检查 Cycle、冻结范围和原始裁决，避免用汇总颜色推断整体 H 的真伪。 |
| 历史归一 | `legacy` | 历史非标准裁决经兼容映射显示，详情保留原始裁决。按原始内容阅读，不能把兼容映射当作正式 Judge Open。 |

运行中、失败、中断、取消或只有运维收尾的 Cycle，在没有终局科学裁决时不产生科学 Outcome，也不自动补成 `open`。`unadjudicated` 是保全展示标签，并非第四种科学裁决。

## 3. 前沿状态表示下一步研究机会

| 页面状态 | 字段值 | 含义 |
|---|---|---|
| 活跃 | `active` | 可作为后续研究来源；实际选题还需结合当前目标与新增科学问题。 |
| 搁置 | `parked` | 暂缓推进，详情中可查看搁置理由。 |
| 已终止 | `closed` | 已退出默认研究前沿。 |
| 未标记 | `unknown`（展示值） | 当前前沿状态缺失或待核验。 |

前沿与 Outcome 分别记录：前沿描述后续研究机会，Outcome 描述本轮证据支持什么。支持后的 H 可以保留活跃资格以衍生新问题；否决后的分支也可继续追查失败机制。`active` 不代表有 Worker 正在运行，`closed` 不代表命题被否决，未标记也不等于已终止。已有后代的 H 仍可活跃。

Research Lead 维护研究前沿，Judge 作科学裁决，SDK 校验并保存状态，Reporter 撰写节点概览与统一研究报告。

## 4. 卡片、颜色与顶部计数怎么读

1. **放大阅读卡片**：缩放大于 60% 时，上半部显示猜想及前沿状态，下半部显示 Outcome；分别点击可进入对应详情。
2. **缩小查看分支**：≤60% 时使用数字概览，默认按前沿着色；工具栏中的 **远景颜色** 可切换为 Outcome 着色。缩放和切换颜色只改变展示。
3. **点击节点 · 科研连线 · 文档统计，打开图例**：前沿色块对应上半部，Outcome 色块对应下半部。少见的结论标签收在“更多”中。
4. **按 H 理解计数**：当前 SQLite 图谱“分支”菜单的“全部 / 活跃 / 搁置 / 已终止 / 未标记”和统计处展开的图例中的 Outcome 分类均按 H 去重。一个历史 H 的多条 Outcome 汇总显示一次；外部资料另计。数字表示猜想数量，Worker 数量和已裁决 Cycle 数量需到对应页面查看。

## 5. 沿连线追溯研究与外部资料

**H→H 科学演化连线**表示有来源、有类型的猜想演化关系。阅读连线和节点详情，确认后继命题如何继承、修正或改换前驱问题。Cycle 编号相邻、页面位置接近本身不构成科学谱系。

新猜想详情开头的 **为什么研究到这里** 解释为什么从来源研究走到当前猜想：先看前序已有结论与关键缺口，再看这一步具体改变什么、为什么现在研究，以及它推进总体目标的哪一部分。主要来源与其他来源分别列出，可点击回看来源猜想和记录的 Outcome。卡片只保留一句短理由，完整说明在详情中展开；本轮报告开头使用同一份承接说明。

没有前序科学来源的初始猜想从原题的未知出发，详情不显示“为什么研究到这里”，也不显示承接理由的空占位。前序被支持也可能留下适用范围或总体目标的缺口；前序被反驳时，应查看具体失败点；尚未裁决与 Judge 已裁决为 Open 要分别理解。承接说明记录提出当前猜想时的研究理由，后续结论仍需查看各轮 Outcome。有前序科学来源但缺少历史承接说明时显示“未记录”，不会自动补写。资料引用不算前序科学来源。

**外部资料（External，E）**保存文献、人工输入、历史 Finding/Decision/总结等来源材料。H→E、E→E 引用连线帮助追溯资料；外部资料本身没有 Judge 裁决权威，是否被采纳为证据需查看对应记录。

## 6. 常用阅读步骤

右侧笔记分为上下两部分：**猜想**说明要检验的命题与条件，**研究结论**给出每轮的裁决、主要依据、适用范围和未决问题。每轮只有一个 **阅读研究报告** 入口。完整报告包含同一概览、正文、可折叠的原始裁决与复现索引；补充文档可在正文中按章节嵌入，并保留来源和冻结版本。报告目录支持按章节阅读，Agent 可用 `report-read` 读取同一内容。旧链接也进入这份报告。

1. 打开顶部“分支”，按前沿状态筛选并定位感兴趣的 H。
2. 点击 H 上半部，有前序科学来源时先读“为什么研究到这里”，了解前序留下什么问题、当前改变什么和为什么研究；再读命题、适用条件与检验标准。初始猜想直接从命题与条件读起。
3. 点击下半部，查看逐轮 Outcome 的冻结检验、Judge 理由、发现、问题和边界，再打开完整 Markdown 报告。
4. 沿科学演化连线查后续猜想，沿资料引用查外部来源。节点左侧索引可帮助跳转前序节点。
5. 使用搜索查找节点和 Markdown；拖动分隔条调整图谱与笔记的比例；悬停分支连线可折叠或展开；用“返回 / 前进”回到此前浏览位置。

例：某轮 H 在指定条件下检验一个机制。`supported` 表示证据在该范围内支持它；`rejected` 表示发现了反证；`open` 表示 Judge 审查后仍无法判定。若该轮在裁决前中止，页面可展示 `unadjudicated` 保全材料。前沿是否活跃则单独决定。

单轮 Outcome 回答“这一轮命题得到了什么结论”；任务级 **Goal Completion** 判断总体研究目标是否完成。阅读总体进度时，应结合任务目标、Scientific Model 和各轮结论。

开发者可进一步查看 [ResearchGraph 设计](../design/ResearchGraph设计文档.md) 与 [Canvas 设计](../design/Canvas设计文档.md)。

工具栏的 **完整图谱** 展开全部分支并适配画布；**适应当前画布、展开全部分支、远景颜色** 直接显示在工具栏，点击 **节点 · 科研连线 · 文档** 统计展开图例。画布左下角是浏览返回/前进，右下角是缩放。按 `/` 聚焦搜索；点菜单外或按 Esc 关闭菜单，展开菜单不会挤压图谱。
