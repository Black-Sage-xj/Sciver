# Literature 真实流程验收：2026-11-18

验收首句：`我对于高分子的拓扑和力学感兴趣,搜搜文献看看.`。使用浏览器新会话，模型 gpt-6-sol / medium，通过 Codex 运行。未创建正式科研任务、H、科学 Evidence 或 Scientific Model。

## 实际结果

实际规划四组互补查询；初次发现保留60条候选，随后精确来源获取合并为89条题录。这个数量包含待筛选命中，不能当作89篇相关论文或89篇已阅读论文。Agent 选读4篇，取得2篇正文，另2篇只有摘要；完成6次科学阅读/综合交付。

两篇正文是 Edwards 等的 Dynamic mechanical response of polymer networks（2000，DOI10.1063/1.1290134，官方 arXiv HTML 57,003字符）和 Lin/Zhao 的 Fracture of polymer networks with diverse topological defects（2020，DOI10.1103/PhysRevE.102.052503，PMC HTML 37,252字符）。保存来源、内容 SHA 和身份核验回执。第二来源的 Marker 转换达到既有240秒上限，第三来源站点403；未将它们计为正文。

主答复给出网络/凝胶中的缠结与滑移、受控拓扑比较、缺陷与断裂三条方向，并区分动态模量、强度、断裂能与疲劳阈值。引用明确论文，说明模型及摘要的适用边界，提供阅读顺序和下一步问题。环链、支化和瓶刷覆盖较少，属于有用的首轮方向图。

## 测试发现并修复

首个新测试因真实集成错误主动停止并保留：筹备读取等待整轮材料锁；读取进程180秒超时早于 Marker240秒，遗留转换子进程。第二轮确认会话运行中导航约0.17秒，转换超时后父子进程均清理。

第二轮还发现预印本补齐 DOI 后“已阅读”标记丢失、内部 paper:N 编号暴露，以及题录合并丢失摘要版本造成的引句假阴性。修复身份别名、引用显示与摘要版本保留。使用已保存的原始交付离线重算 SDK 访问回执：禁止模型、检索和规划的替身均未调用，12个原始响应/Agent JSON 的 SHA 保持不变。作业由 source_access_unverified 暂停变为 review_delivered 完成；原始 Chat 答复仍保留当时的暂停说明，当前状态和报告反映重验结果。

独立 Agent 核查实际正文、摘要、主答复及浏览器体验，确认来源内容、交付边界和主要交互通过验收。结论是首轮兴趣方向调研可用，等待时间与上下文开销仍需优化。该结论来自这一轮实际流程，不代表对其他主题或论文获取环境的质量保证。

## 验证范围与复现

相关整合回归359项与56个子测试通过；后续摘要版本、SDK访问重验、引用显示和浏览器修复另有定向回归。前端 typecheck、构建、Markdown及功能脚本通过。全仓测试分类检查存在11个原有未登记模块，本次新增的3个模块已登记，没有新增未登记模块。

公开回归包括 `tests/test_literature_planning.py`、`tests/test_literature_service.py`、`tests/test_scholarly_fulltext.py`、`tests/test_scholarly_source_resolution.py` 和 `web/tests/test_research_chat_literature_flow.py`。确定性测试验证规划、来源身份、材料访问、摘要版本与引句绑定、取消和页面投影；它们不调用真实模型来替代上述质量验收。

复现真实流程时，新建 Research Chat 会话并输入本页首句，打开 Literature 详情检查查询、候选、选读来源、获取失败原因和报告，再核对主答复的论文引用及阅读方向。模型、公共 API、可读正文和本地转换条件可能改变，因此新的耗时和用量应单独记录。安装与浏览器测试说明见 [首次使用](first-use.zh-CN.md)和 [Web 文档](../web/README.md)。

最后一次显示复核确认：中文标点相邻的加粗恢复正常，详情显示材料重验与历史状态的说明；独立浏览器抽查通过，原始消息和科学交付保持不变。本页公开方法、结果与限制，个人会话、部署信息和原始运行账本不随源码分发。
