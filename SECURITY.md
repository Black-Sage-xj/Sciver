# Security

Please report suspected vulnerabilities privately to the repository maintainers.
If GitHub's private vulnerability reporting feature is enabled for this repository,
use it. If it is unavailable, contact the maintainers privately through GitHub
before making a public disclosure. Do not post credentials, exploit details, or
private research data in public issues.

For deployments, keep API keys and provider accounts outside this repository.
Bind the Web Observatory to a local interface and use an authenticated proxy or
SSH tunnel for remote access. Rotate any credential that may have been exposed.
